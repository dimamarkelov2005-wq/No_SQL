# Лабораторная работа №5: Работа с NoSQL СУБД Redis

**Предмет:** Технологии NoSQL / Базы данных  

---

## 📌 Цель работы
Изучить базовые принципы работы с СУБД Redis, освоить основные типы данных (строки, хэши, списки, множества), механизмы управления временем жизни ключей (TTL), а также реализовать паттерны сессий пользователей, кэширования и аналитики.

---

### Этап 1. Проверка работы среды
Проверена работоспособность базовых команд СУБД Redis для работы со строковыми значениями (запись, чтение и удаление ключа).

## 💡 Выводы
В ходе лабораторной работы освоены ключевые возможности Redis:
1. Использование типов данных `Hash`, `List`, `Set` и `String`.
2. Настройка времени жизни ключей (`EXPIRE`/`TTL`) для автоматической очистки памяти.
3. Применение Redis в качестве хранилища сессий, слоя кэширования и инструмента оперативной аналитики.
